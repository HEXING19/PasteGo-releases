# PasteGo Releases

PasteGo 的公开二进制发布仓库。

- [下载最新版本](https://github.com/HEXING19/PasteGo-releases/releases/latest)
- `appcast.xml`：PasteGo 内置 Sparkle 2 自动更新源
- Release 附件：同时支持 Apple Silicon 与 Intel 的 Universal 2 ZIP

> 当前版本使用 ad-hoc 代码签名且未经过 Apple 公证。更新包另有 PasteGo
> 专属 Ed25519 签名验证；首次从浏览器下载运行时，macOS 仍可能显示
> Gatekeeper 安全提示。

源代码、更新签名私钥和开发配置不存放在本仓库。
